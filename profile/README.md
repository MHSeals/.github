# MHS Seals RoboBoat Team

We're a high school robotics team from James Martin High School in Arlington, Texas, building autonomous surface vehicles for the RoboBoat competition. Learn more about us at [mhsroboboat.com](https://mhsroboboat.com/).

As firm believers in the benefits of open source, we share our competition software so other teams can learn from it, build on it, and contribute.

## Our stack

Our ROS 2 stack connects perception, localization, planning, and control across simulation and the boat.

| Repository | Purpose |
| --- | --- |
| [astro_dock](https://github.com/1unarzDev/astro_dock) | Container workspace, device setup, and deployment. Start here. |
| [mhseals_nav](https://github.com/MHSeals/mhseals_nav) | Sensor fusion, mapping, object tracking, navigation, and mission logic. |
| [mhseals_hardware](https://github.com/MHSeals/mhseals_hardware) | Thruster control and hardware configuration. |
| [mhseals_testing](https://github.com/MHSeals/mhseals_testing) | Sensor checks, thruster testing, characterization, and mission rehearsal. |
| [mhseals_asv_sim](https://github.com/MHSeals/mhseals_asv_sim) | Unity-based ASV simulation. |
| [buoy_model](https://github.com/MHSeals/buoy_model) | Training and tools for buoy detection models. |
| [website2025](https://github.com/MHSeals/website2025) | Our team website. |

> [!IMPORTANT]
> Our software is actively developed; check each repository's README for setup instructions and current limitations.
